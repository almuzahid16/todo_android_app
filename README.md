# Flutter To-Do App

A cross-platform To-Do application built with **Flutter** and **Dart**. This project was developed as part of the **Software Development Project-II (CIT 320)** course at Patuakhali Science and Technology University (PSTU).

## Features
- **Task Management:** Add, edit, and delete tasks.
- **Cross-Platform:** Runs on Android, iOS, Web, and Desktop.
- **State Management:** Efficient state handling for seamless UI updates.
- **Responsive UI:** Clean and modern user interface built with Material Design.

## Technologies Used
- **Framework:** Flutter
- **Language:** Dart
- **IDE:** Android Studio / VS Code

## How to Run
1. Ensure [Flutter](https://flutter.dev/docs/get-started/install) is installed on your system.
2. Clone this repository.
3. Navigate to the project directory: cd flutter-todo-app-master
4. Fetch dependencies: lutter pub get
5. Run the app: lutter run
